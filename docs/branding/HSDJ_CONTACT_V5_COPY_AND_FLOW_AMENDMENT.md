This amendment governs the full Contact-page availability surface. It does not alter the compact header availability treatment.

## Date-first flow

1. Ask for the wedding date.
2. Check availability.
3. If available, offer the consult immediately.
4. Put Stephen Henry's approved review excerpt after the consult action.
5. If a visitor has no date, reveal the message form only when requested.

## Approved visible copy

- Headline: **Have a wedding date?**
- Support: **Check it here. If I'm free, you can book a consult right away.**
- Primary date action: **Check Your Date**
- No-date route: **No date yet? Send me a message.**
- Available headline: **This is the answer you were hoping for. Your wedding date is available.**
- Available support: **Book a 45-minute consult and tell me what you're planning. We'll talk about the wedding, the music, and whether I'm the right DJ for it.**
- Available action: **Book a Consult**
- Manual result: **I need to check this one myself. Send me the date and venue and I'll get back to you.**

The existing factual screen-reader statuses, API response, analytics, Calendly date context, and Stephen Henry source text remain unchanged.
