# HSDJ Physical Visual Vocabulary V1 — External Reference Check

**Purpose:** Validate missing physical-object categories and functional language.  
**Use boundary:** Reference research only. No third-party image from these pages has been copied into the HSDJ source library or vocabulary boards.

## References

### Allen & Heath Xone:96

- Official user guide: <https://support.allen-heath.com/hc/en-gb/articles/43053562464017-Xone-96-User-Guide>
- Confirmed useful hardware language: illuminated CUE switches, channel meters, 60 mm channel faders, crossfader, fader-curve switches, channel strips, and active LEDs.
- HSDJ implication: a real crossfader, adjacent assignment markings, a working meter column and cue-state light are more credible than an abstract equalizer graphic.

### AlphaTheta DJM-A9

- Official product support page: <https://support.alphatheta.com/en-US/articles/16007686521753?product=15882401503257>
- Confirmed useful hardware language: channel faders, MAGVEL crossfader, Sound Color FX rotaries with centre behaviour, effect display and X-Pad lighting.
- HSDJ implication: controls communicate through neighbouring labels, centre marks, travel limits and light—not through isolated icon silhouettes.

### Neutrik XLR cable connectors

- Official product family: <https://www.neutrik.com/en/neutrik/products/xlr-connectors/xlr-cable-connectors>
- Confirmed useful material language: metal shells, pin/socket faces, cable strain relief, locking components and robust assembly.
- HSDJ implication: photograph Patrick’s actual connected cables and strain relief, not only disconnected catalogue-style ends.

### Pro Tapes Pro Gaff

- Official product information: <https://www.protapes.com/pro-gaff-tape/>
- Confirmed useful material language: matte coated cloth, hand-torn edges, marker-friendly surface, conforming around irregular objects, cable bundling and equipment-case labels.
- HSDJ implication: real tape should show fibre, pressure, wrinkles, overlap, handwriting and the object it is doing work on. A clean CSS polygon would remove the very evidence that makes it authentic.

## Research conclusion

The external check confirms that the supplied control-surface crops are directionally accurate. It also confirms the current source gap: the library does not yet contain Patrick-owned crossfaders, working meter columns, connected cables, road-case hardware or real gaffer-tape labels. Those should be captured as original HSDJ photography rather than borrowed or generated.
