# HSDJ Bullet / Control System V1

**Status:** READY FOR PATRICK REVIEW. Not approved for production.

## The bullet law

Generic dots, checkmarks, numbered steps, and icon-library bullets are discouraged when a physical HSDJ control can carry real meaning.

Evaluate these in order:

1. A real photographed knob for a variable, judgment, or tonal decision.
2. A real photographed button or pad for an action, selection, cue, or state.
3. A real photographed switch for an explicit binary choice.
4. A real photographed LED or meter mark for live status or signal.
5. A real photographed fader cap only when progression, level, or changing emphasis is defensible.

## Guardrails

- A control may not be used merely because it looks musical.
- Every control must have a literal text label.
- An inert object must not appear operable.
- Colour cannot be the only state carrier.
- Do not repeat one control until it becomes a decorative icon set.
- A conventional bullet remains preferable when no hardware behavior maps honestly to the content.
- Sitewide fader use remains withheld until Patrick approves the photographic cap and rail samples.

## Current readiness

The visual vocabulary is now materially ready for composition studies. Production adoption is not authorized.
